# R20Exporter Future Input

This folder is a placeholder for a future input path:

R20Exporter ZIP or `campaign.json` -> NormalizedCharacter or Foundry World/Module.

The MVP intentionally does not parse R20Exporter exports. It converts Roll20 character-sheet PDFs locally in the browser.

Any future support must be optional and documented with a clear warning: use R20Exporter only with campaigns you own/control and respect Roll20 terms and marketplace licenses.
